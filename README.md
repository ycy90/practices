# JavaScript Practice

A personal collection of JavaScript exercises and solutions. The goal is to practice problem solving, strengthen core JavaScript skills, and keep a record of progress over time.

## Exercise Sources

Exercises may come from:

- freeCodeCamp
- Bootcamp lessons
- Original exercises written for this collection

## Organization

Exercises are stored in numbered JavaScript files. Each file contains up to 25 exercises.

| File | Exercises |
| --- | --- |
| `practices1.js` | 1–25 |
| `practices2.js` | 1–25 |
| `practices3.js` | 1–14 |

When a file reaches 25 exercises, add the next exercise to a new file: `practices4.js`, `practices5.js`, and so on.

## Exercise Format

Each exercise includes:

1. A numbered title and short task instructions in English.
2. The solution code.
3. One or more sample function calls between console separators, such as `Ex-1---------` and `----------`.

The separators make it easier to identify each exercise's output when a file is run.


## Progress and Review

Use the exercise numbers to keep your place. When revisiting a solution, check whether it meets every task requirement, consider edge cases, and note any JavaScript concepts you want to practice again.
